1

カラム名内階層区切りの分離機能

カラム名に階層区切り文字（"/"「・」等）が埋め込まれ、かつセル値も同じ区切り・個数で分割できる列を検出し、複数カラムに分離する（決定論的・LLM不使用）

テーブルサンプル
変換前
支店帳票プラン1 / 帳票プラン2T/O比
東京支店フレッツ光 / おまかせLAN構築12.5
大阪営業所光コラボ / リモートアクセス9.7
▼分離
変換後
支店帳票プラン1帳票プラン2T/O比
東京支店フレッツ光おまかせLAN構築12.5
大阪営業所光コラボリモートアクセス9.7
T/O比はセル値が数値で区切りを含まないため分割されず維持
2

括弧書き注釈の分離機能

セル値末尾の括弧書き注釈（"東京(本社)"等）を検出し、注釈を別カラムに分離する（単位付き数値の注記は対象外・LLMが新カラム名を命名）

テーブルサンプル
変換前
支店人口
東京(本社)15歳以上人口(人)
大阪(支店)労働力率(％)
▼分離
変換後
支店拠点区分人口
東京本社15歳以上人口(人)
大阪支店労働力率(％)
「人口」列の(人)(％)は単位のため対象外（単位混在の分離に委ねる）。「拠点区分」はLLMが命名
3

階層圧縮カラムの展開機能

階層カテゴリがインデントまたはセル内の階層区切り文字で1カラムに圧縮された表を検出し、レベルごとのカラムに展開する（LLMがレベル名を命名、失敗時は既定名「大分類/中分類/小分類」にフォールバック）。展開直後、子行群の合計と数値が一致するロールアップ行（親レベルの小計・合計）は本機能自身が検出・除去する

テーブルサンプル
①インデント方式
変換前（先頭空白の段差で階層を表現）
地域売上
東日本1600
神奈川事業部1100
横浜支店700
川崎支店400
千葉事業部500
先頭の空白の数（段差）が深いほど下位階層（東日本の下に神奈川事業部・千葉事業部、神奈川事業部の下に横浜支店・川崎支店）
▼展開
変換後（レベルごとのカラムに展開）
地域事業部支店売上
東日本1600
東日本神奈川事業部1100
東日本神奈川事業部横浜支店700
東日本神奈川事業部川崎支店400
東日本千葉事業部500
列名「地域/事業部/支店」はLLMが各レベルの意味を判断して命名（命名に失敗した場合のみ既定名「大分類/中分類/小分類」にフォールバック）
▼ロールアップ行の除去
最終形（本機能自身がロールアップ行を除去）
地域事業部支店売上
東日本神奈川事業部横浜支店700
東日本神奈川事業部川崎支店400
東日本千葉事業部500
東日本行・神奈川事業部行は、子行群の合計と数値が一致するロールアップ行と判定され、本機能自身（集計行の検出・削除・メタデータ保存機能とは別の専用ロジック）が展開直後に除去する。千葉事業部行は子行を持たないため除去されない

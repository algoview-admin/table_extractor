テーブル関係分析とAI分類（Step4）

シート間・テーブル間の関係をAIが分析し、各テーブルの粒度（明細/集計/マスタ/参照）や親子・類似関係を判定する。決定論的に検証できる合計関係がある場合はそれを最優先根拠としてLLMに提示し、値のスケールが大きいだけのシートを集計シートと誤認しないようにする

統合軸・派生テーブル案の生成（Step5）

複数テーブルを1つの縦持ちテーブルに統合する際、統合前から既に同じ意味の軸（列）が存在する場合は新規軸を追加せず既存軸をそのまま採用する。また、集計テーブルと検出済み内訳の差分から、欠落した内訳（派生テーブル）を算出して提案する

3

テーブル選択と最終出力の確定（Step6）

統合案・派生テーブル案・個別テーブルを一覧表示し、ユーザーが最終的に出力するテーブルの組み合わせを選択・確定する。統合案に採用された個別テーブルは二重出力を防ぐため既定で選択解除される
